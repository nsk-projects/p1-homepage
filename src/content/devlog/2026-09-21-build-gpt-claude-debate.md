살다 보면  
일과 삶에서  
정답을 찾는 문제보다  
여러 선택지 중 하나를 고르는 일이 더 어렵다.

어떤 방법이 더 좋은지,  
어느 방향으로 가는 것이 나은지,  
무엇을 먼저 해야 하는지.

이런 문제는  
검색한다고 정답이 나오는 것도 아니다.

<br/>

처음에는 GPT 또는 클로드  
둘 중 하나의 AI에게 물어보고 판단했다.

그런데 한쪽 AI의 의견만 보고  
결정하는 것도 조금 애매했다.

그래서 같은 문제를  
GPT와 Claude 양쪽에 물어보기 시작했다.

<br/>

문제는 그다음이었다.

GPT의 긴 답을 읽고,  
Claude의 긴 답을 다시 읽고,  
서로 다른 부분을 찾아서  
내가 직접 비교하려니 생각보다 복잡했다.

두 AI를 사용하는데  
오히려 내가 정리해야 할 정보가  
더 많아지는 경우도 있었다.

<br/>
그래서 아예  
둘이 서로 토론하게 만드는 방식을 만들었다.

Notion에 별도의 토론 공간을 만들고  
GPT와 Claude가 따라야 할 공통 규칙도 정했다.

<br/>
<img src="/images/devlog/2026-09-21/2026-09-21-gpt-claude-rules.jpg" alt="GPT와 Claude 공통 토론 운영 기준" width="900" />

<br/><br/>

방식은 단순하다.

```text
문제 제시
→ GPT 의견
→ Claude 검토·반박
→ GPT 재검토
→ 다시 Claude
→ 쟁점 정리
→ 최종 판단
```

한 라운드에서
서로의 주장과 근거를 확인하고,
다음 라운드에서는
상대방의 의견을 다시 검토한다.

필요하면 팩트체크도 하고,
잘못된 부분은 수정한다.

<br/>

실제로 운영해 보면
처음 나온 답과
몇 차례 토론을 거친 뒤의 답이
꽤 달라지는 경우가 있다.

처음에는 놓쳤던 조건이 추가되기도 하고,
한쪽이 단순하게 판단했던 부분을
다른 쪽이 지적하기도 한다.

<br/>
<img src="/images/devlog/2026-09-21/2026-09-21-gpt-claude-rounds.jpg" alt="GPT와 Claude의 실제 라운드별 토론 기록" width="900" />

<br/><br/>

물론 자동으로 계속 토론시킨다고
항상 좋은 결과가 나오는 것은 아니다.

내용이 너무 길어지거나
같은 논점을 반복하는 경우도 있다.

그럴 때는 내가 중간에 개입해서
쟁점을 줄이거나
다시 확인해야 할 부분을 정리한다.

AI끼리 토론하게 만들었지만
토론의 방향과
마지막 판단은 결국 내가 맡는다.

<br/>

마지막에는
긴 토론 전체를 다시 읽지 않아도 되도록
핵심 쟁점과 결론을 따로 정리한다.

<br/>
<img src="/images/devlog/2026-09-21/2026-09-21-gpt-claude-summary.jpg" alt="토론 이후 최종 정리" width="900" />

<br/><br/>

이 방식도
정답을 만들어 주는 시스템은 아니다.

GPT와 Claude가 여러 번 검토했다고 해서
그 결론이 반드시 맞는 것도 아니다.

살다 보면
일과 삶에서
정답이 없는 상태로 선택해야 하는 일이 많다.

그럴 때 한 AI의 답을 그대로 받아들이기보다
서로 다른 관점에서 검토하게 만들고,
쟁점을 정리한 뒤
내가 최종적으로 선택하는 방식이
지금은 꽤 유용하다.

<br/>

AI에게 정답을 받는다기보다

내가 더 나은 판단을 할 수 있도록
생각할 재료를 만드는 방식에 가깝다.
